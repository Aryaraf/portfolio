# Arya Ryan Akbar Fadillah - Personal Portfolio

A clean, minimalist terminal-style personal portfolio website showcasing my experience and projects bridging automated server infrastructure and real-time network operations.


### 🛠️ Built With
This portfolio is built using modern web technologies to ensure a fast, responsive, and clean user experience:
*   **[React](https://reactjs.org/)** - UI Library
*   **[Vite](https://vitejs.dev/)** - Build Tool
*   **[Tailwind CSS](https://tailwindcss.com/)** - Styling & Dark Mode Aesthetics
*   **[TypeScript](https://www.typescriptlang.org/)** - Type Safety

### ⚙️ How to Run Locally
If you want to run this project on your local machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Aryaraf/portfolio.git

2. Navigate to the project directory:
    ```Bash
    cd portfolio

3. Install dependencies:
    ```Bash
    npm install

4. Start the development server:
    ```Bash
    npm run dev
